# Customer-churn-ml

HOW TO USE OUR APP
Requirement: Install python 3.12

STEP 1: SET UP A VIRTUAL ENVIRONMENT 
Open your terminal or command prompt in the project folder and run:
Windows: py -3.12 -m venv venv
macOS/Linux: python3.12 -m venv venv

STEP 2: ACTIVE ENVIRONMENT
Windows: venv\Scripts\activate
macOS/Linux: source venv/bin/activate

STEP 3: INSTALL LIBRARIES
In terminal, install all required libraries using the following command:
pip install pandas numpy==1.26.4 matplotlib streamlit shap ydata-profiling scikit-learn xgboost joblib setuptools

STEP 4: RUN APP
In terminal, launch Streamlit using:
streamlit run main.py
